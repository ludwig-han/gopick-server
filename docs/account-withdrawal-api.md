# 회원 탈퇴 API

`DELETE /me`는 로그인한 사용자의 회원 탈퇴를 처리하고 성공 시 204를 반환합니다. 세션을 무효화하며, 기존의 다른 세션도 삭제된 계정으로 인증할 수 없습니다. 계정과 프로필 및 프로필 상세, 북마크·스크랩을 삭제합니다. 기존 이메일은 다시 가입할 수 있습니다.

지원 또는 제안에서 탈퇴 회원이 발신자나 대상자인 기록은 상태에 관계없이 삭제합니다. 완료 프로젝트의 참여 기록은 역할과 참여 시각을 보존하되 프로필 연결을 제거합니다. 프로젝트 멤버 목록에는 `profileId: null`, `name: "탈퇴한 회원입니다"`, `isPublic: false`로 표시됩니다. 준비 중이거나 진행 중인 프로젝트의 일반 멤버는 하차 처리됩니다. 준비 중인 프로젝트의 팀장이 탈퇴하면 프로젝트가 삭제됩니다. 진행 중인 프로젝트의 팀장은 위임 전까지 409를 반환하며, 어느 데이터도 삭제되지 않습니다. 이미 삭제된 프로젝트의 연결도 정리합니다.

## 배포 전 DB 변경

기존 DB는 Hibernate의 `ddl-auto=update`만으로 기존 NOT NULL 제약을 제거한다고 가정할 수 없습니다. 서버 배포 전에 백업 및 배포 절차에 따라 [마이그레이션 SQL](migrations/issue-29-project-member-profile-nullable.sql)을 실행해야 합니다. 새 DB는 JPA 매핑으로 nullable 컬럼을 생성합니다.

알림 PR #56은 이 브랜치의 기준 main에 포함되어 있지 않습니다. 병합 시 null 프로필을 가진 완료 프로젝트 멤버를 알림 수신자에서 제외하고, 탈퇴 계정의 알림 삭제와 스키마를 통합 검증해야 합니다.
